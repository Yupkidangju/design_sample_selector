# DESIGN SPECTRUM 3.0 — AI 바이브 코딩 디자인 쇼케이스

> 겹침 없는 **소수 정예 20종 디자인 사조**를 중립 다크 스튜디오 표본 카드로 비교하고, 클릭 한 번으로 **독립 새 탭 풀스크린 쇼케이스(웹 · 모바일 · 게임 · 대시보드)**와 **원클릭 AI 바이브 코딩 프롬프트(KO/EN)**를 얻는 클라이언트 전용 웹 스튜디오

---

## 주요 특징 (v3.0.0)

1. **소수 정예 20종 큐레이션 (전용 Google Fonts + 커스텀 SVG 아트워크)**
   - **실무 모던 & 클린 (7종):** 스위스 그리드 모더니즘 · 벤토 UI 2.0 · 프로스테드 글래스모피즘 · 리니어 다크 테크 · 소프트 뉴모피즘 · 터미널 모노스페이스 · 모던 스큐어모피즘
   - **그래픽 & 에디토리얼 (6종):** 네오 브루탈리즘 · 하이패션 에디토리얼 · 바우하우스 기하학 · 아르데코 골드 럭셔리 · 리소그래프 인디 콜라주 · 키네틱 애시드 타이포
   - **게임 · 레트로 · 3D · 오가닉 (7종):** 8-Bit 픽셀 아케이드 · 80s 신스웨이브 사이버펑크 · Y2K 크롬 홀로그램 · Frutiger Aero 아쿠아 · 클레이모피즘 3D 버블 · 솔라펑크 에코 오가닉 · 멤피스 팝 아키텍처
2. **중립 다크 스튜디오 메인 갤러리 (`index.html`)**
   - 갤러리 셸의 색을 덜어내 각 디자인 표본 포스터의 서체·팔레트·질감·그래픽 모티프가 왜곡 없이 한눈에 구분됩니다.
   - 검색, 3그룹 필터, 즐겨찾기, 4대 도메인 빠른 열기를 제공합니다.
3. **100% CSS 격리 독립 새 탭 풀스크린 쇼케이스 (`showcase.html`)**
   - 카드 클릭 시 `showcase.html?style=<id>&domain=<web|mobile|game|dashboard>`가 새 탭으로 열려 갤러리 껍데기 없이 100vw × 100vh 순수 디자인으로 감상할 수 있습니다.
   - **4대 실무급 적용 도메인:** 웹 랜딩/서비스 · 모바일 듀얼 스크린 · 스타일별 장르 맞춤 인터랙티브 게임 HUD · SVG 차트 분석 대시보드.
   - 하단 **접이식 미니 플로팅 바**와 **네이티브 `<dialog>` 스펙 서랍**에서 도메인 전환(`1`~`4`), 스타일 탐색(`[`, `]`), **1클릭 AI 프롬프트 복사(`KO` / `EN`)**, 팔레트 복사, `designs.md` 다운로드를 지원합니다.
4. **오디오/군더더기 완전 제거**
   - 기존 음악/BGM/SFX 엔진, 양산형 84종 확장 팩, 깨진 텍스트 치환기(`localizeMarkup.js`), Soft UI 껍데기, 하단 독, 슬라이더 튜너를 전면 제거했습니다.

## 빠른 시작

Node.js 20+ 환경이 필요합니다.

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:5173/design_sample_selector/)
npm run dev

# 카탈로그·오디오 부재 검증 + 단위 테스트 + 프로덕션 멀티페이지 빌드
npm run check

# Headless Chrome 시각/반응형/인터랙션 전수 QA (20종 × 4도메인)
npm run qa:visual
```
